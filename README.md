# Venture Lens

Pressure-test a business idea like a seed investor: weighted scorecard, unit economics, bottom-up market sizing, a pre-mortem with cheap validation tests, and a printable one-pager. One HTML file, no dependencies, works offline.

## Layout

| Path | What it is |
| --- | --- |
| `index.html` | The app. Open it in a browser, that is the whole thing. |
| `screenshots/` | Marketing screenshots at desktop and phone widths. |

## Status

Not yet listed on Gumroad. To ship it, follow the Ratecard pattern:

1. Write `GUMROAD.md` with the listing copy.
2. Build a buyer edition in `dist/` (standalone HTML plus a zip and a quick-start PDF).
3. Create the Gumroad product and upload the zip.

Until then this repo is the source of truth and the lab gallery in TBD-Claude points here.
